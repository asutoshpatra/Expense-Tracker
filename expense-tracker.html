🔑 Use your recovery code

The code you were given when the lock was set up. It works once — you'll get a fresh one after choosing a new password.

🔑 Save your recovery code

This is the only way back in if you forget the password. It is shown once — write it down or save it somewhere that isn't this app.

⚠️ Only a hash of this code is kept, so it cannot be shown again. Lose both the password and this code and the lock can only be cleared by wiping the app's storage, which takes your local data with it.
